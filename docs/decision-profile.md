# Проверка решений одной партии

Администратор может скачать JSON с позициями перед каждым импортированным полуходом обеих сторон.
Выберите один запуск по данным таблицы `game_analysis`.

```sql
SELECT id, engine_name, requested_depth, multi_pv, created_at, completed_at
FROM game_analysis WHERE game_id = :gameId ORDER BY id DESC;
```

После входа в административную зону откройте:

```text
/admin/games/{gameId}/decision-profile.json?gameAnalysisId={id}&topPvLimit=5
```

`gameAnalysisId` обязателен. Для чужой пары партия/запуск ответ 404.
Окно по умолчанию равно 5. Для нулевого или отрицательного окна ответ 400.

| Поле строки | Что проверить |
| --- | --- |
| `decision.root` | FEN, сторона хода, предшествующий ход и сохранённые счётчики. Для первого полухода статус истории NO_PREDECESSOR_IN_IMPORT. |
| `decision.source` | ID партии, запуска и анализа позиции, сохранённые версии извлечения и исходного графа. |
| `decision.assessment` | [ComplexityAssessment](complexity-assessment.md) со всеми сохранёнными кандидатами. Оценки даны для стороны хода. Окно первых N рангов влияет только на window. |
| `decision.candidateEvidence` | В порядке pvRank для каждого кандидата доступны ID исходной записи, UCI, сохранённая PV, версия дельты и события первого хода. |
| `played` | Сыгранный ход, часы, сохранённая потеря и её категория, события сыгранной дельты. Часы и неизвестные оценки допускают null. |

Например, при пяти кандидатах и окне 3 сводка window охватывает первые три ранга.
Оценки, объяснения и графовые события в этом же файле доступны для всех пяти.
Границы полного множества легальных ходов описывает candidateSetComplete.
AVAILABLE с пустым списком означает известное отсутствие события в данной группе.
MISSING_DATA и INCOMPATIBLE_DATA сохраняют своё значение, в том числе во вложенных группах.

Сервис собирает DiagnosticIssue при чтении и проверке строки. Поле code служит для фильтра,
path указывает на поле относительно родительского блока, message поясняет причину.
MISSING_MOVE_ANALYSIS сохраняет строку партии с assessment=null. Некорректные данные позиции
помечаются INVALID_INPUT. Ошибки БД и десериализации прерывают выгрузку.
Штатные причины неизвестности оценки кандидатов остаются в assessment.

В metadata входят параметры запуска и версии правил. По желанию укажите ревизию сборки
через `rightknight.build.revision`. Отсутствующие версии исходных графов имеют значение null.
analyzedPositionCount считает полуходы с сохранённой записью анализа, включая строки с ошибками.
invalidInputCount считает строки с INVALID_INPUT. Исторические версии извлечения признаков,
которых нет в базе, установить по экспортирующей сборке невозможно.

Для ручной проверки сначала рассмотрите исходный FEN и запишите свой выбор. Затем сравните
его с кандидатами, их приемлемостью и событиями, после этого откройте played. Геометрические
события описывают первый ход варианта. Коэффициент сложности на этапе проверки равен 1.0.
